Flock You ESP32

WiFi & BLE Probe / Deauth Detector — Browser-based firmware installer

1
Connect Your Device
Plug your ESP32 board into this computer via USB. Use Chrome or Edge on desktop — Web Serial is not supported in Firefox or Safari.
No drivers are needed on modern macOS / Windows 11.
2
Select Your Board
Choose the hardware you're flashing.
3
Select Firmware
Choose which firmware to run on this board.
4
Configuration (optional)
Everything below defaults to the firmware's standard behaviour — leave it alone and nothing changes. Anything you do change is written to the device's config partition as well as the firmware, and only the options this board can actually honour are shown.
Detections to watch for
Alerts this device can make
Turning an output off only silences this device — detections are still recorded and still sent to the dashboard.
Sensitivity
"High confidence only" makes the device quieter — it can never make it alert on equipment that shares a manufacturer with Flock gear but is not a camera.
5
Flash Firmware
Click Install, select your device's serial port, and wait ~60 s for flashing to complete.

After flashing, open the Dashboard tab above to visualize detections in real-time.
